# Pager

Shows the position in a carousel or swipe row.

- **Figma:** ✲ Foundations › `Pager` (335:336 (Pager dot 335:335)) · shown in Doc / 07c

## Properties

| Property | Type | Values / default |
|---|---|---|
| Pager dot · State | Variant | Default · Active |

## Specs

| | |
|---|---|
| Dot | 8 × 8 · radius 4 · `text/primary` |
| Active | 24 × 8 pill |
| Pager | Five dots in a row |

## Rules

1. Use under swipe rows and carousels only.
2. Match the number of dots to the number of cards.
3. Place it centred, 24 px under the row.
