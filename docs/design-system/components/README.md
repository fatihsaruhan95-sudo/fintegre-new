# Components

All components live on ✲ · Foundations. Place them as instances; don't detach them.

| Component | Figma id | Use |
|---|---|---|
| [Button](button.md) | 334:250 | The action. Primary is a Smoke pill with Graphite text; Secondary is a 1 px outline; Indigo sits inside cards and menus; Text link is a label with an arrow. |
| [Chip](chip.md) | 334:264 | A short fact pinned near a device or card: a check result, a market, a status. |
| [Form field](form-field.md) | 335:320 | One labelled input in contact and newsletter forms. |
| [Select chip](select-chip.md) | 335:327 | One choice in a set of options, for example the program type in Design your program. |
| [Tabs](tabs.md) | 335:290 (Tab 335:289) | Switches the view inside one room, for example the Intelligence chart. |
| [Pager](pager.md) | 335:336 (Pager dot 335:335) | Shows the position in a carousel or swipe row. |
| [Accordion item](accordion-item.md) | 335:279 | A question and answer in the FAQ room (a light Smoke room). |
| [Data row](data-row.md) | 334:275 | One line of data inside a card: a market and its bid, a check and its result. |
| [Stat](stat.md) | 334:280 | A key number with a short label, in a row of stats. |
| [Glass card](glass-card.md) | 335:261 | The surface that holds data: a live valuation, bids, checks, a receipt. |
| [Node](node.md) | 334:294 | The end point of a fibre. |
| [Fibre](fibre.md) | 334:295 | A thin Ice curve that carries data from the check to the device to the value. |
| [Header](header.md) | 336:288 | The site navigation. |
| [Mobile menu](mobile-menu.md) | 336:293 | The full-screen menu opened from the mobile header. |
| [Footer](footer.md) | 336:332 | Indigo glass card at the bottom of the closing room: newsletter, links, legal. |

Icons and logos: see [Icons](../foundations/icons.md) and [Logo](../foundations/logo.md).
