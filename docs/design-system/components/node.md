# Node

The end point of a fibre.

- **Figma:** ✲ Foundations › `Node` (334:294) · shown in Doc / 07b

## Properties

| Property | Type | Values / default |
|---|---|---|
| Type | Variant | Dot · Anchor · Ring |

## Specs

| | |
|---|---|
| Dot | 7 px, inside chips |
| Anchor | 10 px with a 12 px Ice glow, on a device or person |
| Ring | 110–128 px, 1.5 px Ice 90 %, glow 18 px, around the part being checked |

## Rules

1. Every fibre ends on a node.
2. One Ring per room, on the part being checked (screen, battery, camera).
3. Pop nodes in with the spring curve.
