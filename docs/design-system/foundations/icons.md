# Icons

65 components named `Icon / name`, 24 × 24, from Remix Icon (Apache 2.0) via the weeat icon library.

## Rules

1. Use `Icon / …` instances only; swap with instance swap, never paste SVGs.
2. Keep them at 24 (20 inside chips and buttons, 16 in data rows).
3. Colour them with text variables: `text/primary` on dark, `text/on-light` on Smoke, `accent/ice` for status.
4. Use an icon to support a label, never instead of one (except close, menu and arrows).
5. Need a new icon? Take it from Remix Icon (line style), add it to Foundations as `Icon / name` and tell the owner.
