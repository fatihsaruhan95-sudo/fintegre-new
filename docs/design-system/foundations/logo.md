# Logo

Four bars leaning forward. The mark always faces right.

| Component | Variants | Use |
|---|---|---|
| `Logo / Lockup` | White · Graphite · Gradient | Mark + wordmark, the default |
| `Logo / Mark` | Gradient · Graphite · White | Favicons, headers, avatars, tight spaces |

Site file: `assets/header-mark.svg` is the reference orientation.

## Rules

1. Use the lockup by default; the mark alone only for icons, favicons and avatars.
2. Keep the mark facing right: top bar furthest right, bars stepping down to the left.
3. Never mirror, rotate, stretch, skew or recolour the mark.
4. Use White on Graphite; Gradient or Graphite on Smoke and white.
5. Keep clear space of ½ the mark height on every side.
6. Use the 3D mark once per page at most, on dark ground, facing like the flat logo. Its source image is mirrored, so flip the layer.
7. Place logo instances from Foundations; never redraw them.

## Specs

- Minimum size: lockup 96 px wide (25 mm in print) · mark 16 px · favicon 16 / 32 px
- 3D mark: dark ground, indigo glow, same direction as the flat logo
