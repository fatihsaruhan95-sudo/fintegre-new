# Typography

One family, set tight: Geologica for everything people read. One serif italic word per page, at most.

## Text styles

| Style | Font | Size | Line height | Tracking | Use |
|---|---|---|---|---|---|

| Headline | Geologica Regular | 72 | 100 % | −4 % | Room headline |
| Section | Geologica Regular | 56 | 100 % | −3 % | Room headline with longer copy |
| Title | Geologica Regular | 22 | auto | −1 % | Card titles, device names |

## Rules

1. Use Geologica only: Regular for headlines and UI, Light for body and numbers.
2. Apply the text styles; never set size or spacing by hand.
3. Set headlines in sentence case with tight tracking (−3 to −4 %).
4. Use one serif italic word per page, at most, in a headline: the key word, at 1.12 ×.
5. Never use monospace fonts or all-caps eyebrow labels.
6. Write numbers exactly, with units: €612, 58 s, 91 %.
7. Left-align body text in lines of 60–80 characters.
