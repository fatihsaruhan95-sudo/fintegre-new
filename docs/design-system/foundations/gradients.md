# Gradients

Gradients are paint styles. Apply the style; don't rebuild the stops.

| Paint style | Recipe | Use |
|---|---|---|
| `Room light / Hero` | Radial ellipse 654 × 300 at (327, 450) over Graphite: #2236C4 95 % → #1A288F 92.5 % → #121A5A 90 % → #111638 45 % → clear | The room light behind the subject in dark rooms |
| `Room light / Closing` | Radial 1080 × 560 at (50 %, 330): #3047EC 42 % → #141E6E 22 % → clear, plus a linear wash #141E6E 0 % at 55 % → 55 % at 100 % | Closing room only |
| `Fade / Bottom to graphite` | clear → Graphite 92 % at 70 % → Graphite | Melts photos and rooms into the ground |
| `Fade / Text-side scrim` | Graphite → 92 % at 18 % → 35 % at 60 % → clear, left to right | Behind text over a photo |

Data bars use #5D74FF → #3047EC (see [Data & charts](../guidelines/data-and-charts.md)).

## Rules

1. One room light per dark room, placed behind the subject.
2. Every photo meets the ground through a fade; no hard photo edges inside a room.
3. Never use gradients on text, except the closing headline.
