# Review checklist

Go through it before handing a design over or opening a pull request.

## Language
- [ ] One idea per room; text in the left half, ≤ 560 px.
- [ ] Graphite rooms with one room light each; a Smoke room every 3–4 rooms, never two in a row.
- [ ] At most one serif italic word on the page.
- [ ] No monospace, no all-caps labels, no exclamation marks, none of the banned words.

## System
- [ ] Every colour is a variable, every text uses a text style, every shadow/blur is an effect style.
- [ ] Every component is an instance from ✲ Foundations, not detached.
- [ ] Gaps, padding and radii bound to Size variables.

## Imagery
- [ ] Real Apple devices only, a model and colour of their own on this page, iPads upright.
- [ ] People at work, no one looking into the lens, cards beside faces.
- [ ] Logo mark faces right (top bar furthest right), also the 3D mark.
- [ ] No Apple logos, no real customer names.

## Data and copy
- [ ] Numbers exact, with units; invented figures marked “Example data”.
- [ ] Markets from the Baltics, Poland, Finland; neutral customer descriptors.
- [ ] Calls to action verb first, two to four words.

## Accessibility
- [ ] Contrast pairs from [Accessibility](guidelines/accessibility.md) only.
- [ ] Tap targets ≥ 44 × 44, focus ring visible, reduced motion respected, alt text set.

## File
- [ ] Rooms named `NN · Name`; flow has a cover and Ice bands; mobile frame next to desktop.
- [ ] Alternatives in ❖ Alternatives with an orange band, approved designs untouched.
- [ ] → · Start here index updated; placeholders named `Image · replace me`.
