# Connections

Thin Ice fibres carry the data from the check to the device to the value.

## Rules

1. Draw fibres in Ice at 55 %, 1.2–1.5 px wide.
2. Curve every fibre: horizontal tangents at both ends.
3. Use round caps; never add arrowheads.
4. Connect left to right: the check, the part of the device, the card.
5. Keep fibres few and calm; never cross or tangle them.
6. End each fibre on a node: an Ice dot, anchor or ring.
7. Draw fibres on with the fibre easing, once.

## Specs

| | |
|---|---|
| Stroke | 1.4 px (1.2–1.5) · Ice #B7D7FF at 55 % (line/fibre) |
| Curve | Both control points at the horizontal midpoint |
| Ends | Round caps · Node component (Dot 7 px, Anchor 10 px, Ring) |
| Motion | Path trim 0 → 1 · cubic-bezier(.65, 0, .25, 1) · 0.8–1.0 s |
| Components | [Fibre](../components/fibre.md), [Node](../components/node.md) |
