# Imagery: devices

Real, current Apple devices only: large, upright and lit from behind.

## Rules

1. Show real, current Apple devices only; never drawn or mocked-up phones.
2. Give each page its own device model and colour; never reuse the homepage hero device.
3. Show devices large and let the frame edge crop them.
4. Show iPads upright only; never edge-on or lying flat.
5. Light products: room light behind, contact shadow, bottom fade; no blend mode.
6. Photos on black: blend mode Lighten, cropped off the frame edge.
7. Never repeat the same device twice in one view.
8. Never show the Apple logo or use Apple's own marketing photos.

## Specs

| | |
|---|---|
| Room light | Ice 18 % + Indigo 45 %, blur 130, behind the device |
| Contact shadow | Dark ellipse, blur 20, under the device |
| Bottom fade | Graphite 0 → 92 % at 70 % of the height |
| Image fill | Transparent PNG, scale mode Fit, frame at the image's aspect ratio |
| Shadow | Effect style Shadow / Device, corner radius matched to the device |
