# Voice & copy

Say it plainly: short sentences, plain words, real numbers.

## Rules

1. Write short sentences in plain words; lead with the fact.
2. Name what the product does: check, value, route, pay.
3. Use real numbers with units instead of adjectives.
4. Use neutral descriptors: “A Baltic electronics retailer”.
5. Write calls to action verb first, two to four words.
6. Use sentence case; no exclamation marks.
7. Never use the words listed below.

## Specs

| | |
|---|---|
| Words we don't use | revolutionary · seamless · unlock · game-changing · cutting-edge · empower · leverage · magic · world-class |
| Calls to action | Design your program · Talk to us · Get the report |
| Promise | Make every device worth more. |
| Spelling | “colour”, “program” · € before the value (€612) · space before units (58 s, 91 %) |
