# Imagery: people

People run trade-in. We show them at work, with the data beside them.

## Rules

1. Show the people who run programs: associates, telecom staff, technicians, partners.
2. Show people at work; no posing and no one looking into the lens.
3. Place cards beside faces on a scrim, never over a face.
4. Blend photos into Graphite with a side scrim and a bottom fade.
5. Keep skin natural: indigo tint 5 %, never above 8 %.
6. Remove visible brand logos; never use posed stock smiles.
7. Prefer airy, natural-light scenes; avoid an over-polished AI look.

## Specs

| | |
|---|---|
| Light | Natural light, cooled slightly for the dark ground |
| Tint | Indigo 5 % (maximum 8 %) |
| Scrim | Graphite 92 % → 0 % across the text side; bottom fade to 85 % |
| Crop | Faces on the side opposite the text; no faces cut at the eyes |
| Image fill | Scale mode Fill · 16:9 or wider for rooms |
